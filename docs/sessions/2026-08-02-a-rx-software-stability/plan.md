# 2026-08-02 A채널 RX 소프트웨어 안정화 계획

1. 2026-08-01 실차 로그의 A채널 오버런 패턴과 현재 MCP2515 필터 배치를 다시 대조한다.
2. HW3 bit 19/46, TSLLC 비트, Summon 게이트와 송신 주기를 유지한 채 RXB0/RXB1 부하를 분산한다.
3. CAN-A 하드웨어 수신 버퍼를 프레임 해석보다 먼저 RAM 큐로 회수하고 CAN-B 처리 중 A채널 재서비스 간격을 줄인다.
4. CAN 태스크의 긴 대기와 상태 로그 포맷 작업을 분리해 A 폴링 공백을 줄인다.
5. RXB별 수신·오버런, RAM 큐 사용량, 루프 공백과 오버런 처리 단계를 API·Web UI·CSV에 기록한다.
6. 네이티브 테스트, CSV 스키마 검사, Web UI 동기화 검사와 실기 펌웨어 빌드를 수행한다.
7. 날짜와 변경 요약 규칙에 맞는 실차 시험용 펌웨어를 생성하고 다음 로그 판정 기준을 기록한다.

TX Guard 정책 변경은 이번 1단계에서 제외한다. 새 실차 로그로 RX 오버런과 TX hard error의 관계를 다시 확인한 뒤 2단계 적용 여부를 판단한다.
