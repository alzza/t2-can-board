# 채팅 로그 - OTA 확정 UI 단순화

## 요청

- OTA 업데이트 후 확인 팝업이 이중으로 나오지 않게 할 것.
- 녹색·빨간색 펌웨어 확정 화면만 표시할 것.
- 업데이트 후 Web UI를 자동 갱신할 것.

## 반영

- 펌웨어 확정, 이전 펌웨어 복구, 복구 완료 확인, 복구모드 진입 버튼의 중복 브라우저 확인창을 제거했다.
- OTA 후 `/api/status`가 다시 응답하면 현재 페이지에 배너만 적용하지 않고 캐시 방지 주소로 전체 페이지를 재로드하도록 변경했다.
- OTA 시작 전 CAN TX 차단 안내창은 안전을 위해 유지했다.
