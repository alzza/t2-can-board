# 컨텍스트 노트 - OTA 확정 UI 단순화

- 기존 녹색·빨간색 OTA 확정 화면의 버튼은 이미 사용자 의사를 명확히 받는 UI임에도 같은 내용의 브라우저 기본 `confirm()`을 다시 호출했다.
- 기존 재연결 루틴은 `ota_pending_state=2/4`에서 기존 문서의 배너만 갱신하고 새 페이지를 로드하지 않았다. 이 경로를 제거하고 재연결 성공 시 항상 `location.replace()`를 사용한다.
- OTA 시작 전 확인창은 A/B CAN 수정 송신 OFF 저장과 전원 유지를 안내하는 안전 경고이므로 제거 범위에서 제외했다.
