# 2026-07-31 채팅 로그 요약

- 사용자는 ECE R79 처리 조건을 ON/OFF 토글로 만들어 실차에서 정상 조합을
  비교할 수 있게 요청했다.
- Nag MODE 3 삭제 권장안에 동의했다.
- 차량 CAN 통신 경고는 OTA 쓰기 도중이 아니라 OTA 완료 후 발생했으며,
  차량에는 긴급제동 불가 메시지가 표시되었다고 설명했다.
- 이전 경험상 OTA 전후의 무리한 CAN 송신이 원인일 가능성이 있으므로,
  과거의 OTA 전 TX 중단 절차가 여전히 유효한지 반영해 달라고 요청했다.
- 이에 따라 사용자 수동 TX OFF 권장을 유지하면서 펌웨어 차원에서
  A Listen-Only, B 정지, 실패 후 재부팅 전까지 TX 차단을 적용한다.
