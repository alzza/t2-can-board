# 2026-05-10 스마트토크 프로파일 실험 계획

목표.
- 스텔스 PRNG 모드를 삭제하고 Nag Killer 동작을 스마트토크 FSM으로 단일화한다.
- 테스트 단계이므로 `기본값 / A안 / B안` 3단계 프로파일을 유지한다.
- 웹 UI는 라디오 버튼으로 프로파일을 고르게 하고, 선택에 따라 설명과 실제 적용 변수를 간결하게 바꿔 보여준다.
- 2026-05-10 추가: 로그 분석 1차 후보를 `C안`으로 추가한다. C안은 state2 delay 600ms, state2 mild 상한 1.7Nm, strong 400ms/2.10Nm 유지가 기준이다.

범위.
- 펌웨어 설정 구조체와 NVS 저장값에 스마트토크 프로파일을 추가한다.
- Mode A PRNG 주입 경로와 웹 UI 스텔스 문구를 제거한다.
- Mode B 타이밍과 주입 동작은 프로파일 값으로만 바꾼다.
- BUS-OFF/TWAI 복구 로직은 건드리지 않는다.

검증 기준.
- `git diff --check` 통과.
- `pio run -e lilygo_t2can` 빌드 성공.
- 가능하면 관련 native 테스트를 실행하되, 기존 전체 native 실패와 분리해서 기록한다.
- C안 선택 시 `/api/nag-config`와 Web UI 프로파일 설명이 실제 state2/strong 값과 일치한다.
