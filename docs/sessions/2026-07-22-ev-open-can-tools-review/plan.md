# ev-open-can-tools 비교 분석 계획

## 목표

- 첨부된 ev-open-can-tools의 CAN 안정화·주입 정책·Nag Killer·Summon/EU Unlock 구현을 현재 T2-CAN HW3 프로젝트와 비교한다.
- 바로 이식 가능한 개선, 실차 검증이 필요한 개선, 현재 요구와 충돌하는 항목을 구분한다.
- Nag Killer 업그레이드 방향에서 사용자의 선택이 필요한 지점을 근거와 함께 질문한다.

## 범위

1. MCP2515/TWAI 복구와 TX 정책 비교.
2. Summon/EU Unlock 게이트와 HW3 비트 처리 비교.
3. Nag Killer 상태기계·안전 경계·진단·테스트 비교.
4. 플러그인·대시보드·릴리스 도구 중 현재 프로젝트에 유효한 개선 후보 선별.

## 완료 기준

- 각 후보에 근거 파일, 기대 효과, 차량 리스크, 권장 우선순위를 기록한다.
- Nag Killer의 목표 동작을 사용자가 선택할 수 있도록 질문을 남긴다.
