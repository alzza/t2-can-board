# 계획 - 2026-08-05~06 실차 로그 안정성 검증

- 두 CANMOD 통합 로그와 이벤트·시계열 CSV를 날짜별로 짝지어 구조와 시간 범위를 확인한다.
- B채널 `BUS-OFF`, `BUS-ERR`, TEC/REC, TWAI 상태를 서로 다른 지표로 대조한다.
- A채널 RX 오버런, RAM 큐 드롭, TX Guard와 폴링 공백을 정량화한다.
- Web UI의 BUS-OFF 전용 이력이 비어 있는 원인을 코드와 로그 양쪽에서 확인한다.

- 사용자 승인 후 Web UI에서 BUS-OFF와 BUS-ERR를 함께 비교하고 의미를 명확히 설명한다.
- BUS-OFF 진입·복구 결과·전용 이력의 1:1 기록 동작을 native 회귀 테스트로 고정한다.
- Web UI 임베디드 헤더 동기화, 전체 native 테스트와 HW3 펌웨어 빌드를 확인한다.
