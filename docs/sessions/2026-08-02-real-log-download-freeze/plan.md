# 2026-08-02 실차 로그·통합 다운로드 먹통 분석 계획

1. 재부팅 후 받은 통합 로그, 이벤트 CSV, 시계열 CSV의 인코딩·행 수·열 수를 검사한다.
2. 통합 로그 안의 시계열 헤더와 모든 데이터 행의 열 수도 별도로 대조한다.
3. 통합 로그 다운로드 처리에서 20분 버퍼 스냅샷, HTTP 전송, Web UI 폴링 중지 동작을 추적한다.
4. 2026-08-01 로그와 새 로그의 A채널 오버런, 루프 공백, TX 오류와 CAN 오류를 비교한다.
5. 재부팅으로 소실된 증거와 현재 로그로 확정 가능한 사실을 분리한다.
6. CAN 안정화 2단계 진행 여부와 선행해야 할 로그 다운로드 보완안을 정리한다.
