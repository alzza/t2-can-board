## 오늘 추가된 기능: TSLLC

### 기반 JSON Rule

```json
{
  "name": "Enable TSLLC and Continue on Green with Car in Front without confirmation needed from stalk",
  "version": "1.0",
  "rules": [
    {
      "id": 1021,
      "bus": "VEH",
      "mux": 0,
      "mux_mask": 7,
      "ops": [
        { "type": "set_byte", "byte": 0, "val": 0, "mask": 7 },
        { "type": "set_bit",  "bit": 38, "val": 1, "signal": "UI_fsdStopsControlEnabled" },
        { "type": "set_bit",  "bit": 39, "val": 1, "signal": "UI_fsdContinueOnGreenWithCIPV" }
      ]
    }
  ]
}
```

### 이식 결과 검증 (op별 대조)

| Rule op | 공식 동작 | 현재 코드 | 판정 |
|---------|---------|---------|-----|
| `id: 1021` | ID 1021 프레임만 처리 | `if (frame.id != 1021 \|\| frame.dlc < 8) return` | ✅ |
| `mux: 0, mux_mask: 7` | data[0] 하위 3비트 == 0 조건 | `readMuxID(frame) == 0` → `data[0] & 0x07 == 0` | ✅ |
| `set_byte byte=0, val=0, mask=7` | `data[0] = data[0] & 0xF8` | gate 통과 시 이미 하위 3비트=0 → no-op, 생략 정당 | ✅ |
| `set_bit bit=38, val=1` | `data[4] |= 0x40` | `setBit(frame, 38, true)` → byte=4, bit=6 → `data[4] |= 0x40` | ✅ |
| `set_bit bit=39, val=1` | `data[4] |= 0x80` | `setBit(frame, 39, true)` → byte=4, bit=7 → `data[4] |= 0x80` | ✅ |
| `send: true` (기본값) | 수정 프레임 버스 재전송 | `driver.send(frame)` | ✅ |

**결론: 모든 op 정확히 이식됨.**

### 배경

### 이식된 핵심 기능

| 기능 | 내용 |
|------|------|
| **Mode A** | 기존 PRNG 스텔스 토크 (torqWalk 2150~2290 / 변칙 2330~2370), handsOn=1 상시 |
| **Mode B** | ±1.80/±1.50Nm 사이클 토크, handsOn=1 약 28% 빈도 (TSL6P-like), targetId=0x052 |

### 발견된 버그: txFail 항상 0

**원인**
`send()` 반환 타입이 `void`라서 `handlers.h`에서 드롭 여부를 감지할 수 없었음.
드라이버 내부 `txSuppressedCount_`에 실제 드롭이 누적되지만, `bChannelDiag.txFail`에 연결되지 않아 `/api/nag-stats` → `txFail`이 항상 0 반환.

**수정** (`src/main.cpp` nagKillerTask 루프)

```cpp
// 수정 전
bChannelDiag.busoffCount = driverB->getBusoffCount();

// 수정 후
bChannelDiag.busoffCount = driverB->getBusoffCount();
// send() void 반환이므로 드라이버 내부 suppressed 카운터를 txFail로 노출
bChannelDiag.txFail = driverB->getTxSuppressedCount();
```

`txSuppressedCount_`는 다음 두 경우 모두 누적:
1. `twai_transmit()` 실패 (큐 포화, BUS-OFF 포함)
2. `txBackoffUntilMs_` 내 침묵 중 전송 시도
