### 2. Original 모드가 Stealth처럼 동작하지 않는 이유 상세 분석

**질문:** "스텔스모드는 동작이 되는데 오리지널모드는 동작이 안되는것처럼 보인다. 왜 그럴까?"

**최종 분석 결론:**
Original 쪽이 단순히 "토크 방식만 다른 Handler"가 아니었고, 실제 동작 조건이 Stealth와 달랐음.

#### 핵심 원인

1. **Original이 921 프레임 기반 DAS 상태를 보지 않던 시점이 있었음**
   - Stealth는 `dasHandsOnState`를 계속 갱신하며 echo 허용/차단을 판단
   - Original은 초기 상태에서 921를 반영하지 않아 Tesla 상태와 핸들러 판단이 어긋날 수 있었음

2. **Original의 필터 선언과 실제 운용 조건이 불일치했음**
   - Stealth는 880/921 모두를 전제로 동작
   - Original은 한동안 880만 구독하는 형태여서 hands-on 상태 조건을 같은 수준으로 재현하지 못했음

3. **Original에 동일한 스킵 조건/관찰값이 없어서 체감상 '안 되는 것처럼' 보였음**
   - Stealth는 DAS 상태와 토크 워크가 계속 바뀌므로 동작 흔적이 비교적 잘 보임
   - Original은 고정 echo 성격이라 상태 노출이 부족하면 체감상 무반응처럼 느껴질 수 있음

#### 적용한 수정

- `include/handlers.h`
  - `NagHandler_Original`에 `dasHandsOnState` 공유 상태 추가
  - 921 프레임 처리 추가
  - DAS 상태가 `0` 또는 `8`일 때 echo 스킵하도록 Stealth와 유사한 gating 추가
  - `filterIds()`를 `{880, 921}`로 확장

**의미:**
Original도 이제 Stealth와 같은 입력 조건(880 + 921) 하에서 판단하도록 맞춰졌고, Tesla의 hands-on 상태 변화에 따라 더 일관되게 행동하게 됨.

### 5. T-Display-S3의 NO SIGNAL 이슈가 해결됐는지 점검

**질문 요지:**
- 예전에 T-Display에 표시 항목을 추가하면 `NO SIGNAL`이 뜨곤 했는데 지금은 해결된 것인지
- 앞으로 필드를 더 붙여도 괜찮은지

**소스 분석 결론:**
현재 구조에서는 예전보다 훨씬 안전해졌음.

#### 확인한 내용

- `T-Display-S3/src/main.cpp`
  - `decodeTelemetryPacket()`이 prefix-compatible 방식으로 동작
  - `kTelemetryPacketCompatSize = 52` 기준으로 구버전/신버전 패킷을 모두 허용
  - `kLinkMissDebounceFrames = 4`
  - `kLinkTimeoutMs = 3200`

**의미:**
- 송신 payload 뒤에 새 필드를 "끝에만" 추가하면 이전 앞부분 구조는 유지됨
- 수신 측은 최소 호환 prefix 이상이면 파싱 가능
- RF 순간 공백이 있어도 바로 `NO SIGNAL`로 떨어지지 않도록 디바운스가 있음

**주의점:**
- 새 필드는 반드시 구조체 뒤에만 추가할 것
- 송신/수신 양쪽 구조체를 같이 확장할 것
- 이전 필드 순서를 바꾸면 안 됨

### 6. 스텔스 토크 범위와 burst 주기 계산

**질문:** 현재 스텔스모드 코드에서 최대 토크가 얼마까지인지

**당시 코드 기준 해석:**
- 일반 구간: raw `2100..2190`
- excursion 구간: raw `2190 + (r % 41)`

Tesla raw torque 변환식 기준으로 계산하면:
- `2100` → 약 `0.5 Nm`
- `2190` → 약 `1.4 Nm`
- `2230` → 약 `1.8 Nm`

**정리:**
- 평상시 스텔스 토크: 대략 `0.5 ~ 1.4 Nm`
- excursion 포함 최대치: 대략 `1.8 Nm`

추가로 burst 성격도 계산:
- excursion 프레임 수: `3 ~ 5`
- 다음 excursion까지 대기: `125 ~ 225` 프레임
- 100Hz 기준 대략 `1.25 ~ 2.25초` 주기로 짧은 burst 발생

### 7. T-Display 우측 하단에 실제 토크와 스텔스 토크를 둘 다 표시

**질문:** "t-display 화면 우측하단에 토크값나오는데 스텔스모드 토크값도(변조값) 나오게 하려면?"

옵션을 정리한 뒤 사용자가 **2번: 실제 토크와 스텔스 토크를 둘 다 표시**를 선택.

#### 적용한 변경

1. **송신 측 텔레메트리 확장**
   - `tesla-open-can-mod/src/main.cpp`
   - ESP-NOW `struct_message` 끝에 `stealth_torque_nm` 추가
   - Stealth 모드이면서 최근 880 샘플이 유효할 때만 변조 토크를 Nm로 계산해 송신

2. **수신 측 호환 파싱 유지**
   - `T-Display-S3/src/main.cpp`
   - 동일 필드를 구조체 끝에 추가
   - 가변 길이 수신 시 `len`만큼만 복사하도록 수정해

     - 이전 56바이트 포맷
     - 새 60바이트 포맷
     모두 수용 가능하게 유지

3. **UI 상태 및 렌더링 확장**
   - `T-Display-S3/src/ui.h`
