# 채팅 로그 요약

## 사용자 요청

- 차량에서 A채널이 정상으로 보이다 간헐적으로 노란 경고가 표시되는 문제를 분석한다.
- 메인·진단 화면의 모든 통신 플래그와 채널별 검사 로직을 점검한다.
- 포팅 뒤 불용 플래그를 정리하고 진단 로그를 CSV로 저장할 수 있게 한다.
- 차량 대기 후 Summon 호출 지연 원인을 확인한다.
- Web UI를 더 직관적으로 재배치한다.
- 애매한 차량 동작은 임의 변경하지 않는다.

## 사용자 확인

- 차량에서 본 경고 표시는 `A WARN`으로 기억한다.

## 합의한 진행 기준

- `A WARN`을 숨기지 않고 MCP2515 EFLG 원인 비트로 세분화한다.
- 검증된 INO의 `Parked || Summoning`, ID 1021 mux 1, HW3 bit46 조건은 유지한다.
- A TX Guard 임계값과 15초 동작은 차량 CSV 근거가 생기기 전까지 변경하지 않는다.
- 대기 후 지연은 A채널 재수신부터 첫 Summon TX 성공까지 계측해 판단한다.
